MODELS INSTALLATION - QUICK START

FASTEST WAY TO INSTALL MODELS (5-10 minutes)
=============================================

Step 1: Download All Models
---------------------------

  bash scripts/download-models.sh

  OR manually:

  mkdir -p models
  cd models
  
  # Deepfake detection (107 MB)
  wget https://github.com/ondyari/FaceForensics/releases/download/detection_models/xception-epoch-92.pth
  
  # Optical flow (244 MB)
  wget https://github.com/princeton-vl/RAFT/releases/download/v1.0/raft-things.pth
  
  cd ..

Step 2: Verify Downloads
------------------------

  ls -lh models/
  
  Expected output:
  - xception-epoch-92.pth          107 MB
  - raft-things.pth               244 MB

Step 3: Test Models Load
------------------------

  docker compose exec api python3 << 'EOF'
  import torch
  
  model = torch.load('models/xception-epoch-92.pth')
  print("OK Xception loads")
  
  model = torch.load('models/raft-things.pth')
  print("OK RAFT loads")
  EOF

Step 4: Done! System Ready
--------------------------

  Now upload media through frontend and get real analysis results!
  http://localhost:3000

===========================================================================

TROUBLESHOOTING
===========================================================================

Models not downloading:
  OK Check internet connection
  OK Try manual download with curl
  OK Ensure wget/curl installed

Models won't load in Docker:
  OK Check permissions: chmod +x models/*.pth
  OK Verify file size correct (xception ~107MB)
  OK Check Docker has read access to models/

Slow analysis (>30 seconds):
  OK CPU-only mode - expected, use GPU if available
  OK Or use lighter model: MesoNet instead of Xception

Out of memory:
  OK Increase Docker memory limit
  OK Or use smaller models
